## 下载依赖

```bash
npm i vue-i18n
```


## 配置语言包

创建`src/i18n/lang/en.js`和`src/i18n/lang/zh.js`文件，分别存放英文和中文语言包。每个模块的语言包都存放在自己目录的`i18n/lang`目录下。如以下结构：
```bash
# 全局国际化配置文件目录结构
src/
|- i18n/ 
|  |- lang/
|  |  |- en.js
|  |  |- zh.js
|  |- index.js
|- App.vue
|- main.js

# 模块国际化配置文件目录结构
src/
|- views/
|  |- system/
|  |  |- i18n/
|  |  |  |- en.js
|  |  |  |- zh.js
```en.js、zh.js文件内容如下：
```js
export default {
  'message': 'hello world',
  'object': {
    'message': 'hello world'
  }
}
```


## 配置i18n

创建`src/i18n/index.js`文件，代码如下：
```js
// 引入lodash.merge是为了处理语言文件中对象属性强覆盖问题
import _merge from 'lodash.merge';
import { createI18n } from 'vue-i18n';

// element plus 自带国际化
import enLocale from 'element-plus/es/locale/lang/en';
import zhcnLocale from 'element-plus/es/locale/lang/zh-cn';

const messages = {
    'en': enLocale, 
    'zh-cn': zhcnLocale
}; // 用于存储最终的语言消息对象

// 自动引入所有匹配的页面国际化文件
const langFiles = import.meta.glob('@/**/{zh-cn,en}.ts', { eager: true }) as any; 

// 对自动引入的 langFiles 进行分类整理，并合并到messages中
for (const path in langFiles) {
    const key = path.match(/(\S+)\/(\S+).ts/) as string[];
    const langObj = langFiles[path].default;
    const langType = key[2] as 'zh-cn' | 'en';
    if(langObj && langType) {
        messages[langType] = _merge(messages[langType], langObj);
    }
}

// 创建并导出国际化实例
export const i18n = createI18n({
    legacy: false,
    silentTranslationWarn: true,
    missingWarn: false,
    silentFallbackWarn: true,
    fallbackWarn: false,
    locale: 'zh-cn', // 默认语言设置
    fallbackLocale: zhcnLocale.name, // 跌落语言设置为'zh-cn'
    messages, // 使用整理好的语言消息对象
});

```
## 配置main.js
在main.js中引入i18n配置文件，并挂载到Vue实例中：
```js
import { i18n } from '@/i18n/index.js';
createApp(App).use(i18n).mount('#app')
```


## 切换语言

如果在组件中需要切换语言，可以使用`vue-i18n`的`locale`属性来切换语言。如：
```js
import { useI18n } from 'vue-i18n';
const { locale } = useI18n()
locale.value = 'zh-cn';
locale.value = 'en';
```

如果在js、ts文件中需要切换语言，可以使用`i18n`对象中的`locale`属性来切换语言。如：
```js
import { i18n } from '@/i18n/index.js';
i18n.global.locale.value = 'zh-cn';
i18n.global.locale.value = 'en';
```
