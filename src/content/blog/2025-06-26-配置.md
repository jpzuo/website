页面设计器配置详解


## globalConfig

| 参数 | 介绍 |
|:---------:|:----------:|
| headers     | 通用请求头，格式： {token: '我是token'} |
| uploadURL   | 文件上传接口 |
| uploadFileParameter     | 上传文件时文件存储到那个参数内，默认：file |


## pageLinks参数格式

| 参数 | 介绍 |
|:---------:|:----------:|
| value     | 链接/链接分类 |
| label   | 链接介绍/链接分类介绍 |
| children     | 子级 |


## dataLinks参数格式

| 参数 | 介绍 |
|:---------:|:----------:|
| value     | 接口/接口分类 |
| label   | 接口介绍/接口分类介绍 |
| fields   | 接口返回参数集合，具体格式看下方 |
| detailLinkTemp   | 接口数据详情链接模板，格式：/detail?id={id} |
| children     | 子级 |


### dataLinks[].fields 参数格式

| 参数 | 介绍 |
|:---------:|:----------:|
| property     | 参数 |
| label   | 参数别名 |
