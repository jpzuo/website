随着项目越来越复杂，项目体积也越来越大，生成的 vendor 文件也越来越大，导致网站打开的速度越来越慢，因此对包体体积进行优化是很有必要的。以下是我们常用的几种优化方法。

### 1. 代码压缩

vite 会采用 terser 进行 js 代码压缩，cssnano 进行 css 代码压缩，一般不需要再次做处理。

### 2. 开启 gzip

```js
// vite.config.js
import { defineConfig } from "vime";

export default defineConfig({
  server: {
    gzip: true, // 启用 Gzip 压缩
  },
});
```

### 3. 使用 CDN

注意：uniapp 项目中无法对依赖 vue 的依赖进行 cdn 引入，其他可正常使用 cdn 引入。

```js
// vite.config.js
import { defineConfig } from "vite";
import cdnImport from "vite-plugin-cdn-import";

export default defineConfig({
  plugins: [
    cdnImport({
      libs: [
        {
          name: "Vue",
          var: "Vue",
          url: "https://unpkg.com/vue@next",
        },
        {
          name: "VueRouter",
          var: "VueRouter",
          url: "https://unpkg.com/vue-router@4",
        },
        // 添加更多需要从 CDN 导入的库
      ],
    }),
  ],
});
```

### 4. 使用分包

```js
// vite.config.js
import { defineConfig } from "vite";

export default defineConfig({
  build: {
    rollupOptions: {
      output: {
        manualChunks(id) {
          if (id.includes("@antv/g6")) {
            return "antv_g6";
          } else if (id.includes("echarts")) {
            return "echarts";
          }
        },
      },
    },
  },
});
```
