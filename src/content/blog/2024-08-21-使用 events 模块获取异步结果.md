### 场景

在项目中遇到了一个场景，为了不阻塞主线程或支持多线程，但是线程的结果又需要进行返回。如果逻辑简单的场景可以使用 `Promise` 或者 `async await` 将结果进行返回。复杂的场景就需要使用 node.js 中的 `events` 创建一个事件监听器，在程序执行完毕后触发监听事件进行获取。

### 模拟代码

```js
const EventEmitter = require("events");

export default class AsyncSign extends EventEmitter {
  constructor({ express_code = "" }) {
    super();
  }

  fn1() {
    this.fn2();
  }
  fn2() {
    this.emit("listen", "需要传递的数据");
  }
}

// 使用
const asyncsign = new AsyncSign();
asyncsign.fn1();
asyncsign.on("listen", (result) => {
  console.log(result);
});
```
