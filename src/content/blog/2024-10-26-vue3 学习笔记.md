两天时间将 Vue3 + Ts + Pinia 的课程二刷了一遍，感悟还是挺深的，简单记录一下学习笔记。整体与 Vue2 的区别：
1. `setup`函数，其中无法使用`this`，需要使用`getCurrentInstance`获取当前实例。
2. 生命周期统一使用`on`开头，比如：`onMounted`、`onBeforeUnmount`等。
3. 定义内容统一使用`define`开头，比如：`defineProps`、`defineEmits`等。
4. 完美支持`hooks`写法，比如：自带的`useAttrs`、`useSlots`等，当然开发者也要养成使用hooks模式编程的习惯，将Vue3优势发挥到最大。

我感觉变化不是很大，恰恰相反，这种设计使我用起来更顺手，当然在开发过程中还需要注意一些 Vue2和Vue3 的非兼容性改变，具体可以参考 [非兼容性改变-官方文档](https://v3-migration.vuejs.org/zh/breaking-changes/)。


### reactive

如果需要整体修改数据需要通过`Object.assign`去修改
结构`reactive`中的属性在部分情况下会导致结构出来的属性失去响应式，需要使用`toRefs`或`toRef`解构

```js
const obj = reactive({ a: 1, b: 2, c: { d: 4 } });
let { a, b, c } = obj;
a = 5; // 视图不会修改
b = 6; // 视图不会修改
c.d = 7; // 视图会修改
// 堆、栈的理解，js中基础数据类型（string、number、boolean）会直接存储到栈中，
// 所以新变量a, b会直接拷贝栈中对应的数据
// 由于变量c是复杂数据类型，数据存储于堆中，栈指向的是对应的指针，所以新变量c直接使用了对应的指针，
// 由于他们的指针都是相同的所以修改的时候会动态更新

// 保持响应式需要使用toRef 或者 toRefs
let { a, b, c } = toRefs(obj);
let a2 = toRef(obj, "a");
```

### watch

##### 写法

```js
const stopwatch = watch(需要监视的值, (newval, oldval) => {
  console.log(newval, oldval);

  // 如果满足条件删除监听器
  if (逻辑) {
    stopwatch();
  }
});

// 监听对象上具体属性
watch(
  () => obj.key,
  (newval, oldval) => {
    console.log(newval, oldval);
  }
);
```

##### tips

1. 监听的数据类型是`object`和`array`类型无法获取到修改前的值。即`newval`和`oldval`相同
2. 监听使用`ref`定义的`object`和`array`类型需要使用`deep: true`进行深层监听
3. 监听使用`reactive`定义的数据默认开启`deep: true`
4. 监听对象上的具体属性，如果属性是基本类型需要使用`getter函数`监听，如果属性是对象类型可以使用`obj.key`也可以使用`getter函数`，使用前者会导致属性整体改变时无法正确监听到，建议统一使用`getter函数`监听。

### watchEffect

##### 写法

```js
const stop = watchEffect(() => {
  if (num > 10 || str === "lisi") {
    // 满足条件时触发
  }
});

// 停止监听
stop();
```

##### tips

1. 默认开启`deep: true`
2. 自动监听内部依赖的属性，发生修改自动触发

### defineExpose

vue3 中对子组件实例有保护机制，即父组件中通过`ref`调用子组件实例只能访问通过`defineExpose`暴露出来的变量和方法。

```js
// 子组件 setup 中
defineExpose({
  num,
  obj,
});

// 父组件只能通过ref访问子组件中的 num 和 obj 属性
```

### defineProps 和 withDefaults

用于获取和约束父组件传递的参数

```js
// 基础用法
defineProps(['obj1'])

// 限制用法
defineProps<{name: string, list: string[]}>()

// 默认值
withDefaults(defineProps<{name: string, list: string[]}>(), {
  name: '章三',
  list: () => ['1', '2']
})
```

### 生命周期

1. `setup`表示初始化（beforeCreate）和初始化完成（created）
2. `onBeforeMount`组件实例挂载前，`onMounted`组件实例挂载后
3. `onBeforeUpdate`数据修改前，`onUpdated`数据修改后
4. `onBeforeUnmount`组件实例卸载前，`onUnmounted`组件实例卸载后

##### tips

父子组件生命周期执行顺序：
挂载时：先执行父组件的`setup`和`onBeforeMount`，然后执行子组件的`setup`、`onBeforeMount`和`onMounted`，最后执行父组件的`onMounted`
卸载时：先执行父组件的`onBeforeUpdate`，然后执行子组件的`onBeforeUnmount`和`onUnmouted`，最后执行父组件的`onUpdated`
